padding — Padding（内側の余白）
要素の内側の余白を指定する。背景色はpaddingの範囲まで広がる。
【用途】
ボタンやカードのテキストが端に張り付かないようにしたいとき。
【構文】
.box { padding: 16px; }
.box { padding: 8px 16px; }
【関連】
margin → 外側の余白   box-sizing → 幅の計算方法

特徴

初心者からプロまで、コーディング中の「あれ、これなんだっけ」を解決します。

🇯🇵
完全日本語対応
MDNの英語解説ではなく、初心者向けに書き下ろした日本語解説。使う場面・注意点・関連用語まで網羅。
⚡
設定不要・即使える
インストールするだけで動作します。APIキー不要・完全無料。設定変更なしでそのまま使えます。
🎯
エラーパターン付き
よく出るエラーメッセージも一緒に表示。「このエラーはどの用語が原因か」がひと目でわかります。
📐
構造化された解説
用途・構文・関連・注意の4セクションで統一。スキャンして必要な情報だけ読めます。
🔗
MDNリンク付き
詳しく知りたいときはMDN日本語ページへのリンクがホバーパネルに表示されます。
🛠
HTML・CSS・JS対応
3言語に対応。TypeScript・JSX・SCSSファイルでも動作します。

インストール方法

3ステップで完了します。

1
VS Code の拡張機能パネルを開く
左サイドバーの拡張機能アイコンをクリック、または以下のショートカットを使います。
Mac: ⌘ + Shift + X  ／  Windows: Ctrl + Shift + X
2
「Japanese Hover Docs」で検索
検索バーに入力して、kiroworks が公開している拡張機能を選択します。
3
インストールして完了
「インストール」ボタンをクリックするだけで完了です。設定は不要です。HTMLやCSSファイルを開いて用語にカーソルを乗せてみてください。
// settings

設定

VS Code の settings.json から変更できます。

設定名 デフォルト 説明
japaneseHoverDocs.enabled true 解説の表示を有効 / 無効にする
VS Codeの英語ホバーを非表示にする場合（推奨）
// settings.json に追加
"html.hover.documentation": false,
"html.hover.references": false,
"css.hover.documentation": false,
"css.hover.references": false
