インストール方法

3ステップで完了します。

1
VS Code の拡張機能パネルを開く
左サイドバーの拡張機能アイコンをクリック、または以下のショートカットを使います。
Mac: ⌘ + Shift + X  ／  Windows: Ctrl + Shift + X
2
「Japanese Hover Docs」で検索
検索バーに入力して、kiroworks が公開している拡張機能を選択します。
3
インストールして完了
「インストール」ボタンをクリックするだけで完了です。設定は不要です。HTMLやCSSファイルを開いて用語にカーソルを乗せてみてください。
// settings

設定

settings.json に追加することで動作をカスタマイズできます。

settings.json の開き方
VS Code上で ⌘+Shift+P（Mac）または Ctrl+Shift+P（Windows）を押して、
「Open User Settings JSON」と入力してEnterを押すと開きます。
開いたファイルの { と } の中に設定を追加します。
① 英語ホバーをOFFにする（推奨）
VS Code標準の英語ホバーを非表示にして、Japanese Hover Docs の日本語だけをクリーンに表示します。以下の4行をsettings.jsonに追加してください。
settings.json 
{
  // 英語ホバーをOFFにする
  "html.hover.documentation": false,
  "html.hover.references": false,
  "css.hover.documentation": false,
  "css.hover.references": false
}
② 表示セクションをカスタマイズする（オプション）
ホバーパネルに表示するセクションと順番を自由に変更できます。
sections：表示したいセクションだけを配列で指定します。
sectionOrder：表示順を変更します。sectionsで指定したものと同じ項目を並べてください。
選択肢： "用途" "構文" "関連" "注意" "エラー"
settings.json（例：用途と構文だけ表示） 
{
  // 表示するセクションを選択
  "japaneseHoverDocs.sections": ["用途", "構文"],

  // セクションの表示順（sectionsと同じ項目を並べる）
  "japaneseHoverDocs.sectionOrder": ["用途", "構文"]
}
① + ② まとめてコピー
英語ホバーOFF＋カスタマイズの設定をまとめてコピーできます。不要な項目は削除して使ってください。
settings.json（全設定） 
{
  // ① 英語ホバーをOFFにする
  "html.hover.documentation": false,
  "html.hover.references": false,
  "css.hover.documentation": false,
  "css.hover.references": false,

  // ② カスタマイズ（不要なら削除してOK）
  "japaneseHoverDocs.sections": ["用途", "構文", "関連", "注意", "エラー"],
  "japaneseHoverDocs.sectionOrder": ["用途", "構文", "関連", "注意", "エラー"]
}
